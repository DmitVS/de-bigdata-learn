Решение пользователя от 2026-10-03.

Сложную тему объясняют в нескольких формах, по порядку:

1. Текст и схема Mermaid — в уроке, как раньше.
2. Интерактивная HTML-страница — `modules/NN_*/visuals/<тема>.html`. Один файл, без внешних
   библиотек: он открывается в браузере без сети и без сборки. Светлая и тёмная тема.
3. Видео в стиле 3Blue1Brown — `modules/NN_*/visuals/<тема>.mp4`. Сцена Manim —
   `<тема>_video.py` рядом. Озвучка — Piper, голос `ru_RU-ruslan-medium`.

Хранение — в репозитории (выбор пользователя).

Озвучка (уточнение от 2026-10-03): по умолчанию — ElevenLabs, модель `eleven_multilingual_v2`,
стандартный голос George (`JBFqnCBsd6RMkjVDRZzb`), ключ `ELEVENLABS_API_KEY` в `.env`. Голоса из
библиотеки (русские «professional») на бесплатном тарифе через API недоступны (HTTP 402). Черновик
— Piper, голос Ruslan: `make video … VOICE=piper`, кредиты не тратятся. Паузы: тег
`<break time="0.45s"/>` после каждого предложения и `self.wait` между блоками.
Расход: ролик 2:51 — 17 фрагментов, 2 827 символов с тегами пауз; счётчик тарифа после сборки
показал 6 084 из 10 000 (с пробами голосов ≈ 470) — примерно вдвое больше отправленного;
причину смотри на странице Usage. Счётчик обновляется с задержкой в минуты.
Перед финальной сборкой собирай черновик на Piper и проверяй кадры: правки текста озвучки после
финальной сборки снова тратят кредиты.

Инфраструктура: образ `debd/media:local` (`infra/docker/media/`, слой `media.yaml`, профиль
`media`) — Manim 0.21.0, manim-voiceover 0.4.0, piper-tts 1.8.0, ffmpeg, sox; LaTeX не ставится
(формулы не нужны, текст рисует Pango). Сервис озвучки — `scripts/media/piper_service.py`, сборка —
`scripts/media/render.sh` через `make video SCENE=… [Q=l|m|h] [VOICE=piper]`. Сервис ElevenLabs —
`scripts/media/elevenlabs_service.py`. Промежуточные файлы — `data/media`.

**Why:** визуальное объяснение по шагам показывает механизм, а не только описывает его.
**How to apply:**
- Текст озвучки пиши по правилам STE на русском. Английские термины пиши русскими буквами
  («шафл», «Спарк»): голос Piper читает латиницу плохо. Числа пиши словами.
- Проверяй видео по кадрам: `ffmpeg … -vf 'fps=1/6,scale=854:-1,tile=4x5'` и просмотр картинок.
- Проверяй страницу командой `make page-check PAGE=… [W=390] [THEME=dark]`: headless Chrome
  (`chromedp/headless-shell:151.0.7922.109`, CDP) и Node в слое media. Команда ловит ошибки JS и
  консоли, горизонтальную прокрутку и снимает скриншот в `data/shots/`. Проверяй ширину 1100 и 390,
  светлую и тёмную тему. Флаг Chrome `--screenshot` в этом образе зависает — только CDP.
- В SVG задавай цвет текста через `style`, а не атрибутом `fill`: правило CSS `svg text` сильнее
  атрибута. Эмодзи не используй: в Chrome без шрифта эмодзи они пропадают. Пиши ✓ ✗ ● ■ ▶.
- Цифры в страницах и видео — только замеры на стеке из уроков.

на короткие стрелки и выход текста за край кадра — исправлены.

`cdc_debezium` не объясняет WAL и поля события (они в `cursor_vs_log`).
Приёмы, найденные на проверке кадров:
- `Text` в Manim срезает ведущие пробелы: отступы дерева плана задавай сдвигом строк.
- `Paragraph` с подписью, которая начинается с `_`, накладывает строки друг на друга —
  выноси такую подпись отдельным `Text`.
- Подписи справа от длинных полос и строк кода часто уходят за край 14,2 единицы: проверяй
  правый край на сетке кадров.
- Черновик `Q=l` собирается за ~40 с — удобно для итераций; финал — `Q=h`.
