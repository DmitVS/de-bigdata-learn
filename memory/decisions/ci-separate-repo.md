name: ci-separate-repo
description: CI/CD и pre-commit курса готовятся под отдельный репозиторий DE_BigData_Learn, а не под общий repo/
metadata:
  type: decision
---

Решение пользователя от 2026-10-03 (при подготовке модуля 12).

Сейчас курс лежит в общем репозитории `repo/` рядом с другими проектами. GitHub Actions читает
workflow только из `.github/workflows/` в корне репозитория, pre-commit тоже ищет конфиг в
корне git. Варианты: workflow в корне `repo/` с фильтром путей; шаблоны внутри курса; вынос курса
в отдельный репозиторий.

**Выбрано:** модуль 12 готовится под **отдельный репозиторий** — workflow лежат в
`DE_BigData_Learn/.github/workflows/`, конфиг pre-commit — `DE_BigData_Learn/.pre-commit-config.yaml`.
Они заработают после переноса папки курса в свой репозиторий (это шаг лабы 12.1/12.2 для
пользователя). Корень `repo/` и другие проекты не трогаем.

**Why:** курс — самостоятельный проект и будущее портфолио; общий репозиторий с другими
проектами мешает CI и не нужен для резюме.
**How to apply:** все пути в CI — от корня курса; проверять workflow локально (контейнер `act`
или ручной прогон шагов), пока перенос не сделан.
