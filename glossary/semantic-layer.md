# Семантический слой

**Определения метрик в одном месте между витринами и потребителями.** Семантическая модель
описывает сущности (ключи для join), измерения (разрезы) и меры (колонка + агрегация); метрики
строятся из мер. Движок (MetricFlow, Cube, LookML) по запросу «метрика × разрез» сам генерирует
SQL. Цель — одинаковое число на одинаковый вопрос в любом инструменте.

> [!tip] Аналогия
> Книга техкарт ресторана: одно блюдо — один рецепт, кто бы ни готовил.

**У нас:** dbt 1.12 + MetricFlow 0.15 (`dbt-metricflow`, группа `serving`), учебный проект
`modules/10_serving_bi/demo/dbt_semantic`. `oos_share` (ratio) — 19,75 %, среднее долей городов —
20,19 %. Без `alias` в числителе с фильтром MetricFlow 0.15 считал долю как 1.
