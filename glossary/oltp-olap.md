# OLTP и OLAP

| | OLTP | OLAP |
|---|---|---|
| Запрос | несколько строк по ключу | миллионы строк, агрегат |
| Колонок | все | 2–5 из многих |
| Запись | много мелких | редкая массовая |
| Важно | задержка, согласованность | пропускная способность |
| Хранение | построчно, индексы | по колонкам, сжатие |

> [!tip] Аналогия
> Касса пробивает один чек быстро; бухгалтер складывает годовую ленту по одной колонке.

**У нас (замер):** поиск строки — Postgres с индексом 0,06 мс против DuckDB 67 мс; размер —
Postgres 354 МБ (6 колонок) против Parquet 115 МБ (19 колонок).

Клеппман, гл. 3.
