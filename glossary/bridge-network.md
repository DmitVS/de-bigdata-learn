# Bridge-сеть Docker

**Виртуальная локальная сеть внутри хоста**, к которой подключаются контейнеры. На хосте она
видна как интерфейс-мост `br-<id>`. У каждой сети своя [подсеть](subnet.md) и свой
[DNS](dns.md) с именами её контейнеров.

> [!tip] Аналогия
> Офис на этаже здания со своей внутренней АТС и своим справочником. Сотрудники офиса звонят
> друг другу по именам; соседний офис этих имён не знает.

**Compose** создаёт для каждого проекта сеть `<проект>_default` и подключает к ней все
сервисы файла. У нас: `debd_default`, `172.28.0.0/24`.

**Посмотреть:** `docker network ls`, `docker network inspect debd_default`.
