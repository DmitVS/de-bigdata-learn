# Слой образа и copy-on-write

**Слой** — набор изменений файловой системы, который дала одна инструкция Dockerfile (`RUN`,
`COPY`…). [Образ](docker-image.md) — стопка слоёв. Слои неизменяемы и переиспользуются между
образами: общий слой Debian хранится и скачивается один раз.

**Как контейнер пишет поверх слоёв** (драйвер `overlay2`): слои образа — нижние, только чтение;
у контейнера есть свой верхний слой записи; процесс видит их наложенными. Изменение файла
образа сначала **копирует** его в верхний слой (copy-on-write), удаление ставит в верхнем слое
метку-«заглушку».

> [!tip] Аналогия
> Прозрачные плёнки: нижние — отпечатаны раз и навсегда, на верхней можно рисовать; сорвёшь
> верхнюю — рисунок пропадёт, нижние целы.

**Кэш сборки:** если слой N изменился, все слои после него пересобираются (урок 07, Dockerfile).

**Посмотреть:** `docker image history <образ>`, `docker diff <контейнер>`.
