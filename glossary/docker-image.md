# Образ (image)

**Неизменяемый пакет программы со всем её окружением**: файлы ОС, библиотеки, сама программа и
метаданные (какую команду запускать, какие переменные выставить). Состоит из
[слоёв](image-layer.md). Из одного образа запускают сколько угодно [контейнеров](container.md).

> [!tip] Аналогия
> Типовой проект кабинета: по нему можно обставить много одинаковых кабинетов, а сам проект от
> этого не меняется.

**Имя:** `реестр/репозиторий:тег` — `quay.io/lakekeeper/catalog:v0.13.6`. Без реестра — Docker
Hub. Тег — подвижная метка, поэтому у нас теги только фиксированные, никаких `latest`.

**У нас:** `postgres:17.11`, `pgsty/silo:RELEASE…`, `quay.io/lakekeeper/catalog:v0.13.6`,
`curlimages/curl:8.22.0`, собственный `debd/workspace:local`.

**Посмотреть:** `docker image ls`, `docker image history <образ>`.

Связано: [слой образа](image-layer.md) · [контейнер](container.md)
