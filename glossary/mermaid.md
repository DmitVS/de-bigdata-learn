# Mermaid

**Язык описания диаграмм текстом.** Блок ` ```mermaid ` отображается схемой в Obsidian, VS Code,
GitHub. Схема живёт в git рядом с кодом и меняется в той же правке.

| Запись | Смысл |
|---|---|
| `flowchart LR` | схема слева направо |
| `A["текст"]`, `A[("текст")]`, `A(["текст"])` | процесс, хранилище, внешний участник |
| `A --> B`, `A -.-> B`, `A ==> B` | стрелка, пунктир, жирная |
| `subgraph ID["…"]` … `end` | группа |
| `%%` | комментарий |

> [!tip] Аналогия
> Чертёж, записанный текстом: правится как документ.

**Ловушки:** подписи без кавычек со скобками; ID с пробелом; `subgraph` без `end`.

Связано: [ADR](adr.md)
