# S3 (объектное хранилище)

**Протокол хранения объектов (файлов) в бакетах с доступом по HTTP.** Придуман Amazon; у нас
его реализует Silo (форк MinIO), в облаке — AWS S3, GCS, Yandex Object Storage.

- **Бакет** — контейнер верхнего уровня: `landing`, `warehouse`.
- **Ключ** — полное имя объекта: `freshretail/2026-09-28/sales.parquet`. **Папок нет** — слеши
  лишь часть имени; «листинг папки» = поиск по префиксу, на миллионах объектов медленный.
- Объект меняют **только целиком**; все операции — HTTP (`GET`, `PUT`, `DELETE`).

> [!tip] Аналогия
> Огромный склад коробок с окошком выдачи: залы — бакеты, надпись на коробке — ключ.

**Клиенту нужны:** endpoint, ключи (access + secret), region, path-style. Стандартные переменные
`AWS_ACCESS_KEY_ID` / `AWS_SECRET_ACCESS_KEY` читают почти все клиенты.
