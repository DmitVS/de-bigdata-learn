# Звёздная схема (Kimball)

**Таблица фактов в центре, плоские измерения лучами вокруг; запрос — факт + по одному `JOIN` на
измерение.** Проектируется в 4 шага: процесс → grain → измерения → факты.

**Снежинка** — измерения нормализованы (категории отдельными таблицами): больше соединений, в
колоночных хранилищах почти без выигрыша.

**Согласованные измерения** — одно `dim_store` для всех фактов, чтобы отчёты сходились.

> [!tip] Аналогия
> Кассовая лента в центре, справочники вокруг.

**У нас:** звезда FreshRetail — лаба 02.3; в dbt — модуль 05.
