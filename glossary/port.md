# Порт

**Номер «двери» программы** на устройстве: число 1–65535. [IP-адрес](ip-address.md) говорит,
*какому устройству* доставить данные, порт — *какой программе на нём*.

> [!tip] Аналогия
> IP — номер телефона кабинета, порт — добавочный номер. В одном кабинете (контейнере Silo)
> две линии: 9000 — S3 API, 9001 — веб-консоль.

Программа **слушает** порт: ждёт подключений на нём. Если на порту никто не слушает, попытка
подключиться сразу получает отказ — *connection refused* (у curl — код выхода 7).

**У нас:** Postgres слушает 5432, Silo — 9000 и 9001, Lakekeeper — 8181, Jupyter — 8888.

**Посмотреть, кто слушает на хосте:** `ss -ltn` (`l` — слушающие, `t` — TCP, `n` — числами).
