# Слой отдачи (serving)

**Часть стека, через которую витрины доходят до потребителей: дашбордов, аналитиков, отчётов и
приложений.** Три схемы: читать lakehouse напрямую движком запросов, держать копию витрин в
OLAP-СУБД, спрашивать через федеративный движок. Источник правды остаётся один — lakehouse.

> [!tip] Аналогия
> Раздача в столовой: блюда готовят на кухне, выдают с раздачи.

**У нас:** слой `serving.yaml` — ClickHouse (копия витрин для дашборда), Trino (федерация),
Superset (BI), Evidence (отчёты). Город 0 за май: ClickHouse по Iceberg — медиана 29 мс, по
копии в MergeTree — 4 мс.
