# Shuffle

**Перераспределение строк между executors по ключу: задачи map пишут локальные файлы, разбитые по `hash(ключ) mod N`, задачи reduce забирают по сети свои куски. Нужен широким трансформациям (groupBy, join, distinct, orderBy) и всегда разделяет стадии.** Самая дорогая часть запроса; частичная агрегация до shuffle резко его уменьшает. Spill — сброс на диск, когда партиция не помещается в память.

> [!tip] Аналогия
> Развезти кирпичи по цветам между площадками; хорошая бригада сначала считает у себя и возит только итоги.

**У нас:** groupBy по магазинам — 38 КБ shuffle вместо 4,5 млн строк; sort-merge join почасовых продаж по городу — 193 МБ и spill 188 МБ.
