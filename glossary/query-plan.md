# План запроса

**Дерево операторов, которым СУБД выполняет запрос; выбирает его оптимизатор.** Читается снизу
вверх: от чтения таблиц к результату.

- `EXPLAIN` — план без выполнения; `EXPLAIN ANALYZE` — с фактическими строками и временем;
- `TABLE_SCAN`: `Projections` — какие колонки читаются, `Filters` — какие условия применены
  при чтении (pushdown);
- размножение видно по строкам у `HASH_JOIN`.

> [!tip] Аналогия
> Рабочий план старшего бухгалтера по шагам.

**Ловушка:** план — не текст запроса; оптимизатор переписывает (у DuckDB `QUALIFY row_number() = 1`
становится группировкой).
