# Офсет и группа потребителей

**Потребители с одним `group.id` делят партиции топика: каждую партицию группы читает один потребитель. Прочитав, потребитель коммитит офсет в брокере; после перезапуска чтение продолжается с коммита. Lag — сколько событий группа ещё не прочитала. Новая группа без офсетов начинает по `auto.offset.reset` (`earliest` / `latest`).**

> [!tip] Аналогия
> Команда читателей делит тома; у каждой команды свои закладки.

**У нас:** `python -m streaming_demo.consumer --group …` (коммит после обработки), `make rpk ARGS="group describe <группа>"`.
