# Форматы файлов данных

| Формат | Раскладка | Схема | Для чего |
|---|---|---|---|
| CSV | строки, текст | нет | обмен с людьми и чужими системами |
| JSON | строки, текст | нет | вложенность, API |
| Avro | строки, двоичный | в файле | поток сообщений (Kafka) |
| Parquet | колонки, двоичный | в подвале | аналитика |
| ORC | колонки, двоичный | есть | экосистема Hive |

> [!tip] Аналогия
> Список на бумаге · посылки с описью в потоке · коробки с отсеками по колонкам.

**У нас (eval без массивов):** JSON 116,7 МБ · CSV 25 МБ · Parquet zstd 1,1 МБ; `avg` по CSV 43 мс,
по Parquet 1 мс.
