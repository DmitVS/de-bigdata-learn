# Разреженный индекс

**Индекс с одной записью на блок строк, а не на каждую строку.** В ClickHouse — ключ первой
строки каждой гранулы (8 192 строки). Бинарный поиск по засечкам находит гранулы, где значение
может быть, и читает только их. Работает для фильтра по **началу** ключа `ORDER BY`; для
следующих колонок — частично (generic exclusion search).

> [!tip] Аналогия
> Табличка на каждой восьмитысячной коробке: по ней видно, какие коробки открывать не нужно.

**У нас:** `ORDER BY (store_id, product_id, dt, hour)`: `store_id = 348` — 28 гранул из 14 211
(229 тыс. строк); `dt = '2024-05-01'` — весь май, 37,2 млн строк. Проверка — `EXPLAIN indexes = 1`.
