# IP-адрес

**Номер устройства в сети**, по которому ему доставляют данные. Выглядит как четыре числа
0–255 через точку: `172.28.0.3`.

> [!tip] Аналогия
> Номер телефона кабинета. Чтобы дозвониться, нужен номер, а не имя сотрудника.

**У нас:** Silo в сети Docker имеет адрес `172.28.0.3`, Lakekeeper — `172.28.0.2`. Адрес
выдаётся при создании контейнера и **меняется при пересоздании**, поэтому в конфигах пишут
имя сервиса, а не IP (имя в адрес превращает [DNS](dns.md)).

**Особые адреса:**

| Адрес | Смысл |
|---|---|
| `127.0.0.1` | [localhost](localhost.md): «я сам» |
| `0.0.0.0` | в настройке «где слушать»: «на всех моих адресах сразу» |
| `172.16–31.x.x`, `192.168.x.x`, `10.x.x.x` | частные адреса: работают только внутри локальной сети |

**Посмотреть:** `docker network inspect debd_default --format '{{range .Containers}}{{.Name}} {{.IPv4Address}}{{"\n"}}{{end}}'`
