# Естественный ключ

**Набор настоящих полей данных, которые вместе однозначно определяют строку.** В отличие от
суррогатного ключа — искусственного номера, который выдаёт система (`id SERIAL`).

> [!tip] Аналогия
> Человека находят по паспорту (естественный ключ), а не по номеру в очереди (суррогатный).

**Проверка уникальности:**

```sql
SELECT <колонки>, count(*) FROM t GROUP BY ALL HAVING count(*) > 1;  -- пусто = ключ
```

**Ловушка:** ключ, уникальный в каждом файле, может повторяться между файлами — проверяй на
объединении.
