# Trino

**Распределённый SQL-движок без своего хранилища.** Координатор разбирает запрос и строит план,
worker-ы выполняют фрагменты в памяти. Источники подключают **коннекторы**; **каталог** —
коннектор с настройками (файл `*.properties`). Таблица — `каталог.схема.таблица`. Один запрос
может соединять таблицы разных каталогов.

> [!tip] Аналогия
> Переводчик на переговорах: сам ничего не хранит, раздаёт вопрос «странам» и собирает ответ.

**У нас:** `trinodb/trino:483`, UI 8082, `make trino`; каталоги `iceberg` (Lakekeeper, vended
credentials), `postgresql` (`retail_oltp`), `clickhouse`. Лимит контейнера 3 ГБ.
