# Compaction и обслуживание Iceberg

**Мелкие файлы** появляются от частых маленьких записей и мелких партиций; каждый файл — запрос к
S3, подвал и строка в манифесте. **Compaction** переписывает их в крупные (Spark
`rewrite_data_files`; в PyIceberg 0.12 — вручную перезаписью).

**Expire snapshots** удаляет старые снапшоты из метаданных: на них больше нельзя откатиться.
**Remove orphan files** физически удаляет файлы, на которые никто не ссылается. Expire без него
не освобождает место — проверено: после expire в S3 остались все файлы.

> [!tip] Аналогия
> Переупаковать мелкие посылки в коробки; выбросить старые описи; вывезти ненужные коробки.

**У нас:** партиция по дню на 116 млн почасовых строк — 97 файлов по 0,44 МБ.
