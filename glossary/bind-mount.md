# Bind mount

**Папка хоста, подключённая внутрь контейнера.** Изменения видны сразу с обеих сторон: правишь
файл в VS Code — контейнер видит новую версию.

> [!tip] Аналогия
> Окно из кабинета в твою собственную комнату: что поменял у себя, видно в кабинете.

**Запись:** `./postgres/init:/docker-entrypoint-initdb.d:ro` — слева путь (`./`, `../`, `/`).
Относительный путь считается **от папки compose-файла**. `:ro` — только чтение.

**У нас:** `workspace` монтирует весь репозиторий (`../..:/workspace`); `postgres` — init-скрипты;
`lakekeeper-init` — папку со скриптом `init.sh`.

**Посмотреть:** `docker inspect <контейнер> --format '{{json .Mounts}}'`.
