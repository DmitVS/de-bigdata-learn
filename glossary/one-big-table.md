# One Big Table (OBT)

**Заранее соединённая широкая таблица: каждая строка факта уже содержит все атрибуты измерений.**

➕ запросы без соединений; колоночный движок читает только нужные колонки.
➖ изменение атрибута — пересборка всех строк; один grain; нет согласованных измерений.

> [!tip] Аналогия
> Всё переписано в одну огромную ведомость.

**У нас:** FreshRetailNet-50K поставляется как OBT. На практике OBT строят поверх звезды для
самых нагруженных дашбордов.
