# Порядок сортировки (sort order)

**Порядок строк при записи.** Отсортированные данные дают узкие диапазоны min/max в файлах и
группах строк — фильтр по колонке сортировки отсекает почти всё. Плюс длинные серии значений
лучше сжимаются.

В Iceberg порядок можно **объявить** (`sort_order`) — это договорённость для писателей. Spark её
соблюдает; **PyIceberg 0.12 — нет**: сортировать самому (`ORDER BY` перед `append`).

Помогает в основном первой колонке порядка; для двух равноправных — Z-order (Spark).

> [!tip] Аналогия
> Внутри комнаты коробки разложены по номеру магазина.

**У нас:** фильтр по магазину — 1 файл из 20 вместо 11, запрос 9 мс вместо 49 мс.
