# Партиционирование

**Раскладка файлов таблицы по значению выражения от колонки, чтобы фильтр отсекал целые группы
файлов.**

- **Hive-стиль:** отдельная колонка и папки `m=5/`; читатель обязан фильтровать по ней.
- **Скрытое (Iceberg):** спецификация «колонка → преобразование» (`identity`, `year/month/day/hour`,
  `bucket(N)`, `truncate(W)`); значение в манифесте; фильтр по `sale_date` отсекает сам.
  Спецификацию можно менять без переписывания (эволюция партиций).

**Выбор:** колонка почти всех фильтров; размер партиции ≥ ~100 МБ; много значений → `bucket` или
сортировка.

> [!tip] Аналогия
> Комнаты склада по месяцам; опись сама знает, куда класть.

**У нас:** `month` хранит месяцы от 1970 (650 = март 2024). Неделя мая: партиция по месяцу — 1
файл из 5, без партиций — 19 из 20.
