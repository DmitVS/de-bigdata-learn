# Управление доступом (RBAC)

**Аутентификация отвечает «кто это», авторизация — «что ему можно».** В RBAC права выдают
ролям-должностям, людям — роли. Принцип наименьших привилегий: роль получает минимум, нужный для
работы. Уровни прав: каталог/база → схема → таблица → колонка → строка.

> [!tip] Аналогия
> Пропуск с фото (аутентификация) и список залов, куда он открывает дверь (авторизация).

**У нас:** Trino — правила в файле `infra/docker/trino/rules.json` (перечитываются каждые 10 с,
сверху вниз до первого совпадения); Postgres — `CREATE ROLE`, `GRANT`. У учебного Trino нет
аутентификации: пользователь называет себя сам (`--user`).
