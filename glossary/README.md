# Словарь терминов

Общий на весь курс: один термин — одна короткая заметка (определение, аналогия, «у нас», как
посмотреть). Уроки ссылаются сюда, и в Obsidian карточка всплывает при наведении на ссылку.

Шаблон заметки: frontmatter `type: term`, `aliases`, `tags`; разделы — определение жирным,
`> [!tip] Аналогия`, «У нас», «Посмотреть», «Связано».
