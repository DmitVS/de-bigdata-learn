# Способы записи: append, replace, merge

**Как положить загруженные строки в таблицу, где уже есть данные.** append — дописать (повтор = дубли); replace — заменить всю таблицу; merge (upsert) — по ключу обновить или вставить (повтор безопасен); замена партиции — удалить и записать заново, например, день.

> [!tip] Аналогия
> Положить коробки рядом / вынести всё и положить заново / заменить коробку с тем же артикулом.

**У нас:** dlt → Iceberg: append 100 тыс. строк — 1,7 с; upsert тех же строк — 98 с, 100 файлов и 100 снапшотов (пачки по 1 000 строк); `delete-insert` для Iceberg не поддерживается.
