# Метрика

**Число с однозначным определением: формула из колонок, единицы, способ агрегации.**

| Тип | Пример | Агрегация |
|---|---|---|
| Аддитивная | продажи в штуках | складывать по любым разрезам |
| Полуаддитивная | остаток на складе | складывать по магазинам, не по дням |
| Неаддитивная | доля, среднее | пересчитывать из сумм числителя и знаменателя |

> [!tip] Аналогия
> Техкарта: «200 г, 80 °C, 15 минут», а не «вкусно».

**Ловушка:** доля по сети ≠ среднее долей по городам. У нас: 19,75% против 20,19%.
