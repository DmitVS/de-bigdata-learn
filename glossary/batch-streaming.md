# Батч и стриминг

**Батч** — данные обрабатываются ограниченными порциями по расписанию («за вчера»).
**Стриминг** — каждое событие обрабатывается сразу, поток бесконечен.

| | Батч | Стриминг |
|---|---|---|
| Задержка | минуты–сутки | секунды |
| Повтор при сбое | перезапустить порцию | восстановить позицию без потерь и дублей |
| Сложность | низкая | высокая |

> [!tip] Аналогия
> Готовить партиями по расписанию или каждое блюдо сразу по заказу.

**Правило:** начинать с батча; стриминг — только для решений, которые теряют смысл при
задержке в час.

**У нас:** основа — батч; стриминг и CDC — модуль 08.
