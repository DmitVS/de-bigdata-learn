# Сигнал (SIGTERM, SIGKILL)

**Короткое уведомление, которое ядро Linux доставляет процессу.** SIGTERM (15) — «пожалуйста,
завершись»: программа может перехватить его и аккуратно закрыться. SIGKILL (9) — немедленное
уничтожение, перехватить нельзя. Процесс, убитый сигналом N, завершается с кодом **128 + N**:
143 для SIGTERM, 137 для SIGKILL.

> [!tip] Аналогия
> SIGTERM — вежливая просьба освободить кабинет, SIGKILL — охрана выводит под руки.

**`docker stop`:** SIGTERM → ждать 10 с → SIGKILL. Код 137 после `stop` — программа не
обработала SIGTERM.

**Особенность PID 1:** ядро не применяет к нему действие сигнала по умолчанию. Если у программы
нет обработчика, SIGTERM игнорируется. Лечится `init: true` в compose (процесс `tini` в PID 1).
