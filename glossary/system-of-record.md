# Система записи и производные данные

**Система записи** — место, где факт записан впервые и в оригинале. Потеряна — факты
потеряны навсегда. **Производные данные** — всё, что получено преобразованием: витрины,
агрегаты, индексы. Их можно удалить и пересчитать, если есть исходные данные и код.

> [!tip] Аналогия
> Накладная поставщика — оригинал; блюда можно приготовить заново, если есть продукты.

**Важно:** сырой слой хранилища часто становится системой записи для аналитики — источники
хранят историю недолго. **Код в git + сырой слой = всё хранилище.**

Клеппман, гл. 12.
