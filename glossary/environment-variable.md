# Переменная окружения

**Пара «имя=значение» из окружения процесса.** Каждый процесс Linux получает от родителя
**копию** его окружения (возможно, изменённую) и читает оттуда настройки. Так одна программа
работает в разных местах без правки кода.

> [!tip] Аналогия
> Справочник на стене кабинета: инспектор не помнит адреса, а читает их оттуда. Повесили другой
> справочник — пошёл по другим адресам.

**Цепочка у нас:** `.env` → `environment:` в `core.yaml` → окружение контейнера → процесс
`python` → `os.environ["S3_ENDPOINT"]`. Нет переменной — `KeyError`.

**На одну команду:** `ИМЯ=значение команда` — заменить; `env -u ИМЯ команда` — убрать.

**Посмотреть:** `env`, `echo $ИМЯ`; в Python — `os.environ`.
