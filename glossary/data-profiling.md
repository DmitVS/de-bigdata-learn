# Профилирование данных

**Систематическое знакомство с набором данных до того, как на нём что-то строить:** схема,
объём, grain и ключ, пропуски, диапазоны, согласованность, расхождения с документацией.

> [!tip] Аналогия
> Сверка архива с описью до того, как по нему составлять отчёты.

**Проверка качества** формулируется как правило и записывается запросом, который возвращает
**число нарушений**: 0 — правило выполняется. Такую проверку легко превратить в автотест.

| Тип | Шаблон |
|---|---|
| Полнота | `count(*) - count(col)` |
| Диапазон | `count(*) FILTER (WHERE col < a OR col > b)` |
| «У X одно Y» | `GROUP BY X HAVING count(DISTINCT Y) > 1` |

**У нас:** DuckDB `SUMMARIZE` для обзора, лаба 00.3. Дальше — модуль 09 (тесты качества).
