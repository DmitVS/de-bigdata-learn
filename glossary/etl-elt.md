# ETL и ELT

**ETL** — забрать → преобразовать отдельной программой → загрузить готовое.
**ELT** — забрать → загрузить как есть → преобразовать SQL внутри хранилища.

| | ETL | ELT |
|---|---|---|
| Сырые данные в хранилище | нет | да |
| Ошибка в правилах | перезабрать из источника | пересчитать из сырых |
| Кто пишет | инженер, код | AE, аналитик, SQL |

> [!tip] Аналогия
> ETL — резать продукты в машине поставщика; ELT — разгрузить как есть и резать на своей кухне.

**У нас:** ELT (dlt → Iceberg → dbt). ETL оправдан для персональных данных (модуль 11).
