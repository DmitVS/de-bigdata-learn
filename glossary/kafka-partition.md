# Партиция Kafka и ключ

**Партиция — независимый лог внутри топика со своей нумерацией офсетов. Producer выбирает её по `hash(ключ) mod число_партиций`, поэтому события одного ключа идут в одну партицию по порядку; без ключа порядок между событиями не гарантирован. Партиции — единица параллелизма чтения.**

> [!tip] Аналогия
> Параллельные тома журнала; том выбирают по фамилии.

**У нас:** демо-показания погоды с ключом `city_id` в топике на 3 партиции — города разного размера, партиции неравные (город 0 — половина строк датасета).
