# Healthcheck

**Команда, которую Docker периодически выполняет внутри контейнера, чтобы узнать, готов ли
сервис.** Код выхода 0 — проверка прошла, иначе — провал. По истории проверок контейнер получает
статус `starting` → `healthy` / `unhealthy`.

> [!tip] Аналогия
> Вахтёр каждые 5 секунд звонит в кабинет: «Работаете?». Сотрудник в здании (процесс запущен) —
> ещё не значит, что он отвечает на звонки (сервис готов).

**Параметры:** `test` (`CMD` / `CMD-SHELL`), `interval` (первая проверка — через него после
старта), `timeout`, `retries` (провалов подряд до `unhealthy`), `start_period` (льготное время).

**Правило:** проверять тем же путём, каким обращаются соседи (у Postgres — по TCP).

**Посмотреть:** `docker inspect <контейнер> --format '{{json .State.Health}}'` — статус и 5
последних проверок.
