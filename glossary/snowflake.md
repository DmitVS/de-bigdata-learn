# Snowflake

**Облачное хранилище данных: хранение, вычисления и сервисы — у поставщика.** Вычисляют
виртуальные склады (XS…6XL, кредиты посекундно, автоостановка), данные хранятся в
микропартициях с min/max для отсечения. Загрузка: файлы → stage → `COPY INTO` (журнал загруженных
файлов). Есть time travel, zero-copy clone, обмен данными; умеет таблицы Iceberg в вашем бакете.
Выбор против lakehouse — по стоимости владения (TCO) и привязке к поставщику.

> [!tip] Аналогия
> Аренда в бизнес-центре: службы включены, платишь за время работы бригад.

**У нас:** модуль 13 (опционально) — облако вне Docker; `dbt-snowflake` 1.12 в группе `cloud`,
`dbt parse` работает без аккаунта; SQL проверен по документации, не на стеке.
