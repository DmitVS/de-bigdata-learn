# Исключение (exception)

**Способ Python сообщить о проблеме**: код выбрасывает объект-исключение (`raise`), выполнение
прерывается, и исключение летит вверх по цепочке вызовов, пока его не перехватит
`try … except`. Не перехватили — программа печатает **трейсбэк** и завершается с кодом 1.

> [!tip] Аналогия
> Сигнал тревоги, который передаётся вверх по начальству, пока кто-то не примет его и не
> запишет в журнал.

- `try / except / finally` — перехватить / обработать / убрать за собой при любом исходе.
- `assert условие, "текст"` — выбросить `AssertionError`, если условие ложно.
- `with ресурс:` — гарантированно закрыть ресурс, даже при исключении.
- Трейсбэк читают **снизу вверх**: последняя строка — что случилось, выше — где.

**У нас:** в `check_stack.py` каждая проверка «падает» исключением, а `main()` перехватывает их
и печатает `FAIL <класс>: <текст>`.
