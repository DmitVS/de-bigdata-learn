# Маршрут

**Правило «пакеты для таких-то адресов отправляй через такой-то интерфейс»**. Таблица
маршрутов решает, куда уходит каждый пакет. Побеждает самое **точное** правило (с большим
числом после `/`).

> [!tip] Аналогия
> Указатели на развилке: «номера 172.28.0.* — во внутреннюю АТС, остальные — оператору».

**На хосте** (`ip route`):

```text
0.0.0.0/1 via 10.33.0.2 dev tun2            ← половина интернета — в VPN
128.0.0.0/1 via 10.33.0.2 dev tun2          ← вторая половина — в VPN
172.28.0.0/24 dev br-aba673a07129           ← наша сеть Docker — в мост
```

VPN так «забирает себе» весь трафик, не удаляя обычный маршрут по умолчанию. Побочный
эффект: Docker видит, что все адреса уже кому-то принадлежат, и не может сам выбрать
подсеть для новой сети.

Связано: [подсеть](subnet.md) · [сетевой интерфейс](network-interface.md)
