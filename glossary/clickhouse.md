# ClickHouse

**Колоночная OLAP-СУБД с собственным хранилищем на локальном диске.** Хранит каждую колонку
сжатым файлом, сортирует строки по `ORDER BY` и находит нужные гранулы по разреженному индексу.
Таблицы семейства [MergeTree](mergetree.md). Умеет читать файлы (`file()`, `s3()`) и Iceberg
через REST-каталог (`DataLakeCatalog`).

> [!tip] Аналогия
> Раздача с подогревом: копия блюд под рукой, выдача без очереди на кухню.

**У нас:** `clickhouse/clickhouse-server:26.8.15.10`, HTTP 8123 (`/play`), клиент — `make ch`.
Почасовые продажи — 116,4 млн строк, 2,28 ГиБ → 142,5 МиБ на диске; загрузка из Parquet — 6,7 с.
