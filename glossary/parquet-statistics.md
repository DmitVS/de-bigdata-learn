# Статистики Parquet (min/max)

**Минимум, максимум и число `NULL` для каждого куска колонки каждой группы строк, записанные в
подвале.** По ним движок решает, можно ли пропустить группу, не распаковывая её.

Статистики умеют только **исключать**: значение вне `[min, max]` — группы точно нет; внутри —
может быть.

> [!tip] Аналогия
> Этикетка на отсеке: «магазины с 210 по 230».

**Работают, если данные отсортированы** по колонке фильтра. У нас строки идут по магазину: фильтр
`store_id = 214` задевает 39 групп из 4 500, а `dt = '2024-05-01'` — все 4 500.

Iceberg хранит такие же статистики **для каждого файла** в манифестах.
