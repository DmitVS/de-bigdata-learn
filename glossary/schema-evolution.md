# Эволюция схем

**Изменение схемы таблицы без поломки старых данных и читателей.**

- **Обратная совместимость** — новый код читает старые данные.
- **Прямая** — старый код читает новые данные.

Iceberg связывает колонки с файлами **по ID поля**, а не по имени или позиции: переименование
безопасно, новая колонка в старых строках — `NULL`, ID не используются повторно. Типы — только
расширение: `int → long`, `float → double`, рост точности `decimal`. `long → int`,
`string → long` — `ValidationError`.

> [!tip] Аналогия
> Опись ссылается на номер отсека, а не на подпись — подпись можно переклеить.

**Без Iceberg:** Parquet связывает по имени — переименование даёт две половинчатые колонки.
