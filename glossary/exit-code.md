# Код выхода (exit code)

**Число, с которым завершается любой процесс**: `0` — успех, всё остальное — ошибка (смысл
конкретных чисел определяет программа). В shell код последней команды лежит в `$?`.

> [!tip] Аналогия
> Отметка подрядчика в акте: «0 — сделано», любая другая цифра — номер проблемы.

**В Docker:** статус `Exited (0)` у one-shot контейнера — норма, `Exited (1)` — сломалось.
`depends_on: condition: service_completed_successfully` ждёт именно кода 0.

**Примеры:** curl — 6 (имя не найдено), 7 (порт не слушается), 22 (HTTP-ошибка с `-f`);
`check_stack.py` — 0 или 1; `docker compose up --exit-code-from <сервис>` — код сервиса.

**Посмотреть:** `команда; echo $?`, `make ps`.
