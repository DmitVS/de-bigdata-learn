# Smoke-тест

**Быстрая проверка «система вообще живая?»**: каждый компонент отвечает и компоненты работают
вместе. Бизнес-логику не проверяет. Название — из электроники: включили плату и смотрят, не
пошёл ли дым.

> [!tip] Аналогия
> Утренний обход здания с чек-листом: свет есть, двери открываются, телефоны отвечают.

**Правила хорошего smoke-теста:** быстрый; проверяет все пути доступа (у нас — прямой к S3 и
через каталог отдельно); одна упавшая проверка не останавливает остальные; убирает за собой;
возвращает честный [код выхода](exit-code.md).

**У нас:** `scripts/check_stack.py`, запуск — `make check`. Дальше в курсе: тесты dbt (05),
проверки качества данных (09), CI (12).
