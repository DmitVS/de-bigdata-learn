# Нормализация вложенных данных

**Раскладка вложенного JSON в плоские таблицы: вложенный словарь — колонки через `__`, вложенный список — дочерняя таблица `<родитель>__<поле>` со ссылкой `_dlt_parent_id` и позицией `_dlt_list_idx`.** Таблицы Arrow dlt не раскладывает: вложенные типы остаются как есть.

> [!tip] Аналогия
> Посылку с отделениями распаковать: содержимое отделений — на отдельную полку с биркой «из посылки №…».

**У нас:** промо из API: `items` → `promotions__items`; день продаж строками-словарями → `…__hours_sale` на 1,2 млн строк и 35,6 с, тем же днём в Arrow — 0,2 с. Upsert не удаляет из дочерней таблицы элементы, пропавшие из списка.
