# Data Vault

**Модель для интеграции многих источников и полной истории:** хабы (бизнес-ключи), связи (связи
между хабами), сателлиты (атрибуты с историей версий). Ключи — хэши бизнес-ключа (`md5`), что
позволяет грузить таблицы параллельно.

➕ новый источник — новый сателлит; полная история с источником и временем загрузки.
➖ запросы из десятков соединений: аналитики работают со звёздами поверх DV.

> [!tip] Аналогия
> Отдельно картотека номеров, отдельно связи, отдельно все версии описаний.

**Место:** слой интеграции (silver) в организациях с множеством источников и аудитом.
