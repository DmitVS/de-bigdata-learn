# Роли в data-команде

**Участки общей работы от сырого факта до решения.** Роли различаются тем, что производят и
для кого, а не инструментами.

| Роль | Производит | Потребитель |
|---|---|---|
| Data engineer | пайплайны, хранилище, платформу | AE, DA, DS, системы |
| Analytics engineer | чистые модели и витрины с тестами | DA, BI |
| Data analyst / BI | ответы, отчёты, дашборды | менеджеры |
| Data scientist | модели, эксперименты | бизнес, продукт |
| ML engineer | модель в продакшене | сервисы |
| Платформа / DevOps | инфраструктура | инженеры |

> [!tip] Аналогия
> Фабрика-кухня: DE строит кухню и линии поставок, AE пишет техкарты полуфабрикатов, DA
> собирает блюдо под заказ, DS придумывает рецепт, MLE ставит его на поток.

**Ловушка:** роль в вакансии определяют по обязанностям, а не по заголовку.
