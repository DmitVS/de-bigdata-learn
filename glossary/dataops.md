# DataOps

**Практики, которые делают изменения пайплайна частыми, маленькими и безопасными:** всё в git,
pull request с ревью, автоматические проверки (pre-commit, CI), тесты данных, отдельные окружения
dev / CI / prod, наблюдаемость и SLO. Скорость и надёжность поставки меряют четырьмя метриками
DORA: частота выкатки, время до прода, доля неудачных изменений, время восстановления.

> [!tip] Аналогия
> Конвейер для изменений: маленькие детали, контроль на каждой, счётчик брака.

**У нас:** история курса — коммиты до 184 файлов и 18 390 строк (большие пачки); метрики
своего пайплайна — лаба 12.4, `ops/dora.md`.
