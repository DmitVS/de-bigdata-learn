# Контейнер

**Запущенная из [образа](docker-image.md) программа**: обычный процесс Linux, которому ядро
показывает файлы образа вместо файлов хоста, даёт отдельную сеть
([namespace](network-namespace.md)) и **свой слой записи** поверх слоёв образа.

> [!tip] Аналогия
> Кабинет, обставленный по типовому проекту. Бумаги на столе (слой записи) выбрасывают при
> сносе кабинета; сейф в архиве ([том](volume.md)) остаётся.

**Жизненный цикл:** `create` → `start` → процесс работает → процесс завершился: `Exited (N)`,
где N — [код выхода](exit-code.md). `docker stop` / `start` сохраняют слой записи; удаление
контейнера (`make down`) удаляет и слой.

**У нас:** `debd-postgres-1` = `<проект>-<сервис>-<номер>`.

**Посмотреть:** `make ps`, `docker diff <контейнер>`, `docker inspect <контейнер>`.

Связано: [образ](docker-image.md) · [том](volume.md) · [код выхода](exit-code.md)
