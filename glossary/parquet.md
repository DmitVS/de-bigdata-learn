# Parquet

**Колоночный формат файлов для аналитики.** Строки делятся на группы строк (row groups), внутри
группы каждый столбец хранится отдельным сжатым куском со статистикой (min, max, число null).
В конце файла — футер со схемой и указателями.

**Почему быстро:** читаются только нужные столбцы; по min/max пропускаются целые группы строк;
однотипные значения подряд хорошо сжимаются (у нас — ZSTD).

> [!tip] Аналогия
> Коробка, где данные разложены по столбцам, а на крышке этикетка «store от 1 до 500».
> Ищешь store = 900 — эту коробку можно не открывать.

**Arrow** — родственный колоночный формат **в памяти**; общий язык PyIceberg, DuckDB, Polars.

**Посмотреть:** `pyarrow.parquet.ParquetFile(f).metadata` — row groups, статистика по столбцам.
