# Train / eval split

**Разделение датасета на часть для обучения модели (train) и часть для проверки её качества
(eval, test).** Делят случайно или по времени. Для прогнозов временных рядов правильно по
времени: eval идёт после train, иначе модель «подсмотрит будущее», и оценка будет завышена.

> [!tip] Аналогия
> По одной коробке учатся, по другой сдают экзамен. Если экзаменационные билеты лежали в
> учебной коробке, оценка ничего не стоит.

**Для DE:** разделение нужно исследователям. Для пайплайна аналитики это части одной истории:
их загружают вместе, а способ разделения записывают в документацию.

**У нас:** FreshRetailNet-50K поставляется двумя файлами `train.parquet` и `eval.parquet` —
лаба 00.3.
