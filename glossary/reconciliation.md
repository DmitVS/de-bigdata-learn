# Сверка (reconciliation)

**Сравнение источника и копии: число строк, контрольные суммы по колонкам, разница ключей в обе стороны (`ANTI JOIN`).** Единственный способ поймать тихие потери загрузки: число строк может совпасть при одной потере и одном дубле.

> [!tip] Аналогия
> Инвентаризация: сверить учёт с тем, что лежит на полках.

**У нас:** DuckDB подключает Postgres и Iceberg в одном запросе (`ATTACH … TYPE postgres` / `TYPE iceberg`); в модуле 09 сверка станет проверкой качества.
