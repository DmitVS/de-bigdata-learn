# Федеративный запрос и pushdown

**Один SQL к нескольким системам без копирования данных.** Движок старается отдать работу
источнику (**pushdown**): фильтр, список колонок, агрегат. **Динамический фильтр** — ключи
маленькой стороны join отсекают строки большой стороны ещё при чтении. Что ушло в источник,
видно в `EXPLAIN`: `constraint on [колонка]`, `Query[SELECT … GROUP BY …]`.

> [!tip] Аналогия
> Перевести фильтр заранее, чтобы каждая страна прислала три строки, а не миллион.

**У нас:** продажи закрытых магазинов — Postgres вернул 3 строки, Iceberg — 1,53 млн, после
динамического фильтра осталось 5 580. С `lower(status)` pushdown пропадает.
