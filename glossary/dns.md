# DNS

**Служба, превращающая имя в IP-адрес**: `silo` → `172.28.0.3`, `pypi.org` → `151.101.x.x`.
«Резолвить имя» = узнать его адрес через DNS.

> [!tip] Аналогия
> Телефонный справочник. В справочнике офиса есть только сотрудники этого офиса.

**В Docker:** в каждой пользовательской сети есть встроенный DNS по адресу `127.0.0.11`. Он
знает имена сервисов **своей** сети, остальные имена спрашивает у DNS хоста.
**Хост** встроенным DNS Docker не пользуется, поэтому имя `silo` с хоста неизвестно.

**Проверить:** `make shell`, затем `getent hosts silo` → `172.28.0.3  silo`.
На хосте та же команда ничего не выведет.

**Если имя неизвестно:** curl завершится с кодом 6 — *Could not resolve host*.
