# Перцентиль (p50, p95, p99)

**Значение, быстрее которого выполнились p% запросов.** p50 — медиана, типичный опыт; p95, p99 —
хвост. Среднее прячет выбросы и не описывает ничей реальный опыт.

**Усиление хвоста:** страница из N параллельных запросов медленная с вероятностью 1 − 0,99ᴺ
(при N = 10 ≈ 9,6%).

> [!tip] Аналогия
> Как долго ждут самые неудачливые 1% заказов.

**Посчитать:** `statistics.quantiles(t, n=100, method="inclusive")` → `qs[49]`, `qs[94]`,
`qs[98]`. Метод `exclusive` (по умолчанию) экстраполирует: при числе замеров меньше 100 он может дать
p99 > максимума.

**У нас:** запрос по городам за день — p50 ≈ 71 мс, p99 ≈ 85–90 мс, первый (холодный) ≈ 98 мс.
