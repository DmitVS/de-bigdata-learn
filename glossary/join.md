# JOIN — соединение таблиц

**Для каждой строки слева находит все строки справа, подходящие под условие `ON`; каждая пара —
строка результата.** Сколько совпадений — столько строк.

| Тип | Результат |
|---|---|
| `INNER` | только пары |
| `LEFT` | все слева, без пары — `NULL` справа |
| `SEMI` | строки слева, у которых есть пара; без размножения |
| `ANTI` | строки слева без пары |
| `CROSS` | каждая с каждой |

> [!tip] Аналогия
> Для строки кассовой ленты найти её карточку в справочнике.

**Главная ловушка:** ключ не уникален справа → [размножение строк](fan-out.md).
