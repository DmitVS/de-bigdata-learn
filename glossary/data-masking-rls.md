# Маскирование колонок и фильтр строк (RLS)

**Маска заменяет значение колонки выражением, фильтр строк добавляет условие к каждому запросу
роли.** Их применяет движок, поэтому обойти их через другой клиент нельзя. В Postgres фильтр строк
— row-level security: `ENABLE ROW LEVEL SECURITY` + `CREATE POLICY … USING (…)`.

> [!tip] Аналогия
> Цены на полках заклеены; в чужие залы склада не пускают.

**У нас:** Trino: партнёр видит `sales` как `NULL`, менеджер города 0 — 97 строк из 1 746.
Postgres: роль без политики после включения RLS видит **0 строк без ошибки**; владелец таблицы
политику обходит (898 строк) — нужна `FORCE ROW LEVEL SECURITY`.
