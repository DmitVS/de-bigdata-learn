# Warehouse, data lake, lakehouse

| | Warehouse | Data lake | Lakehouse |
|---|---|---|---|
| Данные | внутренний формат СУБД | файлы в S3 | Parquet в S3 + метаданные Iceberg |
| Схема | при записи | при чтении | при записи, с эволюцией |
| Транзакции | да | нет | да |
| Движки | только свой | любые | любые, через каталог |
| История | дорого | дёшево | дёшево |

> [!tip] Аналогия
> Холодильная камера с описью · большой сарай · сарай с полками, описью и замками.

**Цена lakehouse:** больше компонентов (каталог, формат, обслуживание файлов).
