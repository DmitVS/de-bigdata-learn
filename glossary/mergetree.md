# MergeTree

**Семейство движков таблиц ClickHouse.** `INSERT` сортирует пачку по `ORDER BY` и пишет её
новой **частью**; фоновые **слияния** объединяют части одной партиции. Внутри части строки
разбиты на **гранулы** по 8 192 строки; первичный индекс хранит **засечку** — ключ первой строки
гранулы. Варианты движка делают при слиянии дополнительную работу: Summing — складывает,
Aggregating — объединяет состояния агрегатов, Replacing — оставляет последнюю версию строки.

> [!tip] Аналогия
> Склад, где коробки стоят по порядку, а на каждой висит табличка с адресом первой коробки.

**У нас:** 2 вставки одного магазина → 10 частей (по месяцам), `OPTIMIZE … FINAL` → 5 частей
уровня 1. Больше 1 000 частей в партиции — вставки замедляются, больше 3 000 — `Too many parts`.
