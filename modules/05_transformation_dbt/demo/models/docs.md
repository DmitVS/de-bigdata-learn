{% docs precipitation %}
Осадки за день из датасета (`precpt`). Единицы в описании датасета не указаны; используем
только для сравнения дней между собой.
{% enddocs %}

{% docs mart_city_rainy_days %}
Сколько дождливых дней было в каждом городе сети за период датасета и какая была средняя
температура. Отвечает на вопрос: в каких городах погода чаще всего могла влиять на продажи.
Дождливым считается день, когда средние по магазинам города осадки не меньше переменной
`rainy_threshold` (по умолчанию 10 — примерно 15% самых дождливых дней сети).
{% enddocs %}
