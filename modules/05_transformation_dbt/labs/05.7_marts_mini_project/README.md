## Objective

Построить три витрины, которые отвечают на бизнес-вопросы сети из модуля 01, проверенные
тестами, описанные и опубликованные в Iceberg `gold`. Это слой capstone, который в модуле 06
будет запускать оркестратор, а в модуле 10 — показывать дашборд.

## Tasks

### Task 1. Дизайн

**Expected result / Definition of Done:**
- Для каждой витрины в README: бизнес-вопрос, потребитель, grain, метрики с формулами и
  единицами, источники в графе
- «Эффект промо» учитывает смешанные факторы (модуль 01, урок 02): что сравнивается с чем

### Task 2. Модели

**Expected result / Definition of Done:**
- `mart_sales`, `mart_out_of_stock`, `mart_promo_effect` (имена — по своему соглашению) поверх
  факта и измерений
- Ответы на бизнес-вопросы модуля 01 получаются запросами к витринам и совпадают с ответами лабы
  02.6 (или расхождение объяснено)

### Task 3. Качество и документация

**Expected result / Definition of Done:**
- Тесты ключей и диапазонов, unit-тест на ключевую формулу каждой витрины
- Описания всех колонок; `check_docs.py` из лабы 05.4 — код 0
- Exposure дашборда сети ссылается на три витрины

### Task 4. Capstone

**Expected result / Definition of Done:**
- `dbt build` всего проекта с публикацией — зелёный; витрины в `gold`
- В [`capstone/README.md`](../../../../capstone/README.md) — раздел «Transform»: граф слоёв,
  витрины с grain, как собрать, как проверить
- Пункты DoD модуля 05 в [`ROADMAP.md`](../../../../ROADMAP.md) отмечены по факту
