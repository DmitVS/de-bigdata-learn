## Tasks

### Task 1. Проект

**Expected result / Definition of Done:**
- `capstone/transform_sqlmesh/` с отдельным файлом DuckDB; одна витрина и её входы (staging и
  intermediate) как модели SQLMesh; входные bronze — из Iceberg или из `data/raw`
- `sqlmesh plan --auto-apply` строит prod; результат совпадает с dbt-витриной (запрос сравнения)
- Аудиты на ключ и тест на формулу проходят

### Task 2. Изменения

**Expected result / Definition of Done:**
- Два изменения в dev: одно Non-breaking, одно Breaking — предсказание класса до плана и
  фактический класс в README
- `table_diff prod:dev` для обоих; выкатка в prod; доказательство, что выкатка не пересчитывала
  данные

### Task 3. Сравнение

**Expected result / Definition of Done:**
- Таблица dbt vs SQLMesh по твоему опыту (не пересказ урока): объём кода, время до первого
  результата, понятность ошибок, поведение при изменении, чего не хватило
- Вывод: что выбрал бы для команды из трёх аналитиков и почему
