## Tasks

### Task 1. Измерения

**Expected result / Definition of Done:**
- `dim_store`, `dim_product`, `dim_date` в `models/marts/` — таблицы; у каждой суррогатный ключ
  (dbt_utils) и естественный ключ
- `dim_date` покрывает весь период датасета без пропусков, тип даты — `DATE`; признаки дня
  (день недели, выходной, праздник из bronze) — колонками
- Строка «неизвестно» в измерениях — если она была в твоём дизайне 02.3

**Steps:**
1. `dbt deps` для dbt_utils; `date_spine` — урок 05, шаг 5 (ловушка с концом периода).

### Task 2. Факт

**Expected result / Definition of Done:**
- `fct_sales_daily` на grain из лабы 02.3, со ссылками на измерения через суррогатные ключи и
  мерами продаж, часов без остатка, промо
- Материализация выбрана и обоснована в README (урок 02, шаг 6)
- Сумма продаж в факте равна сумме в staging (запрос в README)
- Если выбрал инкремент — второй запуск подряд не меняет сумму и число строк

### Task 3. Intermediate и граф

**Expected result / Definition of Done:**
- Общие расчёты вынесены в `int_*`, витрины не ссылаются друг на друга по кругу
- `dbt ls -s +fct_sales_daily` показывает ожидаемую цепочку; скриншот графа или вывод — в README
- `dbt build` всего проекта — зелёный
