# Лаба 08.4 · Flink SQL: продажи и out-of-stock по магазину и часу

**Модуль:** [08 · Стриминг и CDC](../../README.md) · **Дата начала:** YYYY-MM-DD · **Статус:** ⬜

## Objective

Посчитать потоком то, что бизнес хочет видеть «почти сейчас»: продажи и часы без товара по
магазину и часу, с правильной обработкой времени события и опоздавших событий, с записью в
Iceberg. Навык — окна, watermarks, состояние и сквозная гарантия.

## Tasks

### Task 1. Источник и окна

**Expected result / Definition of Done:**
- Таблица-источник Flink на топике 08.2 с временем события и watermark (терпимость обоснована)
- Окно час × магазин: продажи, часы без товара; результат за один день совпадает с расчётом
  DuckDB по исходным файлам (сверка)

### Task 2. Опоздавшие события

**Expected result / Definition of Done:**
- Producer с долей опоздавших (свой режим, как `--late` в демо); показано, сколько событий
  отброшено при твоей терпимости, и как это меняется при двух других значениях
- Решение для витрины: какую терпимость взять и что делать с опоздавшими (обновление,
  пакетный досчёт) — в README

### Task 3. В Iceberg с exactly-once

**Expected result / Definition of Done:**
- Долгоживущее задание пишет окна в Iceberg `silver`; видны коммиты на чекпоинтах
- Сбой: taskmanager перезапущен посреди потока (`docker restart`); после восстановления число
  строк и суммы в Iceberg совпадают с расчётом без сбоя (сверка) — дублей нет
- Число файлов таблицы через час работы и план обслуживания (компактизация, модуль 07)
