# Лаба 08.5 · Мини-проект: потоковая витрина out-of-stock и SCD2 из CDC

**Модуль:** [08 · Стриминг и CDC](../../README.md) · **Дата начала:** YYYY-MM-DD · **Статус:** ⬜

## Objective

Соединить поток продаж и поток изменений учётной системы в витрину, которая показывает
out-of-stock почти в реальном времени и знает, какой ассортимент действовал в каждый момент.
Плюс эссе: где у твоего pipeline exactly-once, а где нет.

## Tasks

### Task 1. SCD2 справочников из CDC

**Expected result / Definition of Done:**
- История ассортимента (магазин × товар) из событий CDC: версии с `valid_from`/`valid_to`, удаление
  закрывает версию; в Iceberg
- Сверка: текущие версии = таблица `retail_oltp.assortment`; число версий товара, у которого
  генератор менял категорию, соответствует числу изменений

### Task 2. Витрина out-of-stock

**Expected result / Definition of Done:**
- Витрина «часы без товара по магазину и часу» только для товаров, которые **в этот момент** были
  в ассортименте (соединение с версией справочника на время события — temporal join или своя логика)
- Витрина обновляется потоком; задержка от события до строки — измерена

### Task 3. Эссе и capstone

**Expected result / Definition of Done:**
- Эссе (1–2 страницы) в `capstone/streaming/README.md`: где в твоём pipeline at-least-once, где
  exactly-once и за счёт чего; как обработаны опоздавшие; что будет при сбое каждого компонента
  (Redpanda, Connect, Flink, Lakekeeper)
- Раздел «Streaming» в [`capstone/README.md`](../../../../capstone/README.md); пункты DoD модуля 08 в
  [`ROADMAP.md`](../../../../ROADMAP.md) отмечены по факту
