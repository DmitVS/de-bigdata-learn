# Лаба 10.3 · Superset: дашборд сети (мини-проект модуля)

**Модуль:** [10 · Витрины и BI](../../README.md) · **Дата начала:** YYYY-MM-DD · **Статус:** ⬜

## Objective

Собрать дашборд сети, который отвечает на бизнес-вопросы capstone: продажи, часы без товара,
промо и погода. Это критерий 6 [рубрики capstone](../../../../capstone/rubric.md): минимум
распределение по категориям и динамика во времени. Тренируем датасеты, метрики, чарты, фильтры и
честную визуализацию.

## Tasks

### Task 1. Подключения и датасеты

**Expected result / Definition of Done:**
- Подключения ClickHouse и Trino; Test Connection — успешно
- Датасет витрины продаж: временная колонка отмечена, колонкам даны понятные подписи
- Метрики датасета: продажи, доля часов без товара, доля продаж в промо — формулы из сумм; в
  README каждая формула и её проверка запросом в `make ch` (числа совпадают)

**Steps:**
1. Подключи базы по шпаргалке урока 05.
2. Создай датасет и метрики. Для каждой метрики найди одно число вручную в `make ch` и сравни.

### Task 2. Чарты на вопросы

**Expected result / Definition of Done:**
- Не меньше пяти чартов, каждый подписан вопросом, на который отвечает:
  - распределение по категориям: доля часов без товара по городам или категориям;
  - динамика во времени: продажи и доля без товара по дням;
  - промо: продажи в промо и без промо;
  - погода: продажи в дождливые и сухие дни (вычисляемая колонка или виртуальный датасет);
  - одно ключевое число (Big Number) с трендом
- Хотя бы один чарт строится через Trino (федеративный запрос из лабы 10.2 как виртуальный датасет)
- Для двух чартов в README — SQL из View query

**Steps:**
1. Для каждого вопроса выбери тип графика по таблице урока 05, шаг 5.
2. Проверь каждый чарт на пять обманов из урока: ось, средние долей, круг, неполный период, цвет.

### Task 3. Дашборд

**Expected result / Definition of Done:**
- Дашборд «Сеть: продажи и наличие» с native filters «Город» и «Период»; фильтры действуют на
  нужные чарты (Scoping)
- Cross-filtering по клику на город работает
- Время загрузки дашборда после Force refresh — в README; самый медленный чарт найден и ускорен
  (через ключ ClickHouse или предрасчёт из лабы 10.1)
- Экспорт дашборда (Dashboards → … → Export) — в `capstone/serving/superset/`
- Скриншоты — в `capstone/serving/screenshots/` и ссылка из `capstone/README.md`

**Steps:**
1. Собери дашборд, добавь фильтры, настрой Scoping.
2. Найди самый медленный чарт по `system.query_log` ClickHouse (колонка `query` содержит SQL от
   Superset) и разберись, что он читает.
3. Проверь, что экспорт восстанавливается: удали дашборд и импортируй файл обратно.
