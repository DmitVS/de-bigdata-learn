## Objective

Региональные менеджеры каждую неделю смотрят пятёрку лучших магазинов своего города. Реализовать
эту сводку тремя движками — DuckDB SQL, Polars, pandas, — убедиться, что результаты одинаковы, и
выбрать движок по замеру, а не по привычке.

## Спецификация сводки

Вход — `train.parquet`. Выход — по строке на (неделя, город, магазин), только 5 лучших
магазинов города в неделю.

| Колонка | Тип | Как считается |
|---|---|---|
| `week_start` | DATE | понедельник недели даты `dt` |
| `city_id` | BIGINT | город магазина |
| `store_id` | BIGINT | магазин |
| `sales` | DOUBLE | сумма `sale_amount` за неделю |
| `oos_share` | DOUBLE | доля часов без остатка: сумма элементов `hours_stock_status` / (24 × число строк) |
| `promo_sales_share` | DOUBLE | доля продаж в строках с `activity_flag = 1` от `sales` |
| `city_sales_share` | DOUBLE | `sales` магазина / сумма `sales` всех магазинов города за неделю |
| `rank_in_city` | BIGINT | ранг по `sales` по убыванию внутри (неделя, город), `rank` |

Строки с `rank_in_city <= 5`, сортировка по `week_start, city_id, rank_in_city`. Результат
каждого движка — Parquet-файл в `data/tmp/` (вне git).
