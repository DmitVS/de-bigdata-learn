## Tasks

### Task 1. Почасовой вид

**Expected result / Definition of Done:**
- Функция «дневные строки → почасовые»: из массивов `hours_sale` и `hours_stock_status` — строки
  (магазин, товар, день, час, продажа, статус наличия)
- Тесты: обычный день; массив короче 24 элементов; NULL в массиве; номер часа совпадает с
  позицией в массиве (проверь по описанию датасета, с какого часа начинается массив)

### Task 2. Метрики out-of-stock

**Expected result / Definition of Done:**
- Функции: часы без товара за день; доля часов без товара в рабочие часы (границы рабочих часов
  обоснуй по `stock_hour6_22_cnt`); продажи в часы с товаром
- На каждую функцию — тесты с граничными случаями (все часы есть, ни одного, граница рабочих
  часов, дробная доля), ожидания посчитаны руками

### Task 3. Ошибка, которую поймал тест

**Expected result / Definition of Done:**
- В README — хотя бы одна ошибка, найденная тестом до запуска на данных: что было, какой тест
  упал, как выглядел диф chispa
- `python -m pytest -q capstone/spark/tests` — все зелёные; без кластера — `SKIPPED`, а не ошибки
