### Task 2. Разбор 10 вакансий

**Expected result / Definition of Done:**
- Файл `vacancies.csv` рядом с этим README: минимум 10 вакансий DE от **разных** компаний
- Колонки: `id, company, title, role_by_duties, must, nice, link`; навыки в `must` и `nice` —
  через `;`, нормализованы
- В README: сколько вакансий оказались не DE по обязанностям, и какая роль на самом деле

**Steps:**
1. Найди 10–15 вакансий «Data Engineer» разного уровня и из разных доменов.
2. Разбери каждую по пяти частям (урок 01, шаг 4). `role_by_duties` определи по глаголам
   обязанностей, а не по заголовку.
3. Составь словарь синонимов (например, `postgres = postgresql = pg`) и приведи навыки к одному
   написанию. Словарь запиши в README.
4. Сохрани таблицу в `vacancies.csv`. Значения с запятыми бери в двойные кавычки.

### Task 3. Частотность навыков и план

**Expected result / Definition of Done:**
- Файл `queries.sql` с запросом частотности: отдельно по `must` и по `nice`,
  `count(DISTINCT id)` и процент
- Файл [`interview/market.md`](../../../../interview/market.md): размер выборки; ядро (навыки
  в >50% вакансий как обязательные); частые «плюсы»; таблица «навык → модуль курса → мой
  уровень сейчас (0–3)»; 3 главных пробела
- Пункт DoD модуля в ROADMAP отмечен

**Steps:**
1. В `make sql` прочитай CSV: `read_csv('modules/01_role_and_architecture/labs/01.1_roles_and_market/vacancies.csv')`.
2. Адаптируй запрос из «Попробуй сам» урока 01, шаг 4: сначала по колонке `must`, затем по `nice`.
3. Проверь нормализацию: `SELECT DISTINCT skill` — нет ли одного навыка под двумя именами.
4. Сопоставь навыки с модулями курса по таблице этапов (урок 01, шаг 3).
5. Запиши `interview/market.md`. Рядом с процентами пиши абсолютные числа.
