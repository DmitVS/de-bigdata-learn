## Objective

Сформулировать 5–10 бизнес-вопросов сети, на которые будет отвечать capstone, и для каждого
доказать запросом, что данные позволяют на него ответить. Набор вопросов становится
техническим заданием на загрузку, модели, витрины и дашборды следующих модулей.

## Tasks

### Task 1. Черновик вопросов

**Expected result / Definition of Done:**
- 10–12 вопросов-кандидатов, каждый с решением, которое он поддерживает
- Покрыты минимум 4 темы из: наличие на полке, промо и скидки, погода, праздники, города и
  магазины, категории, часы суток
- Для каждого отмечено, не упирается ли он в ограничения датасета (урок 02, шаг 3)

**Steps:**
1. Для каждой темы придумай решение, которое мог бы принять кто-то в сети: закупки, маркетинг,
   управляющий магазина.
2. От решения иди к вопросу (урок 02, шаг 1), а не наоборот.
3. Сверь каждый вопрос с таблицей «чего нет» из урока 02, шаг 3. Вопросы в рублях
   переформулируй в относительные или вычеркни.

### Task 2. Проверка осуществимости

**Expected result / Definition of Done:**
- Для каждого кандидата — запрос в `queries.sql`: есть ли данные, есть ли вариация (размер
  каждой сравниваемой группы), и первый результат
- Для каждого вопроса вида «влияет ли X на Y» — проверка минимум одного смешанного фактора
  со сравнением «наивно / внутри срезов»
- Вычеркнутые вопросы остаются в README с причиной

**Steps:**
1. Для каждого вопроса посчитай `count(*)` в каждой группе, которые будешь сравнивать.
2. Посчитай метрику наивно, затем внутри однородных срезов (урок 02, шаг 4: город × месяц, тот
   же товар × магазин). Запиши обе цифры.
3. Для долей проверь, что считаешь из сумм, а не средним долей (урок 02, шаг 2).
4. Реши, оставить вопрос, переформулировать или вычеркнуть.

### Task 3. Карточки в capstone

**Expected result / Definition of Done:**
- В [`capstone/README.md`](../../../../capstone/README.md), раздел «Бизнес-вопросы», — 5–10
  карточек по формату урока 02, шаг 5; все поля заполнены
- У каждой карточки в поле «Ответит» — витрина с grain одной строки или дашборд
- Пункт DoD модуля в ROADMAP отмечен

**Steps:**
1. Отбери 5–10 вопросов, прошедших проверку. Хотя бы один — про наличие на полке с учётом
   скрытого спроса.
2. Заполни карточки. Поле «Проверка осуществимости» — ссылка на запрос и результат одной строкой.
3. Grain витрины выбери по самому детальному разрезу метрики (урок 02, шаг 5).
