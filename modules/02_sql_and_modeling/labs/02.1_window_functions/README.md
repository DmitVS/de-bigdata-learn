### Разминка: соединения, NULL, итоги (урок 01)

1. **Будни и выходные.** Средние продажи по городам отдельно для будней и выходных
   (`isodow`). В каком городе выходные дают самый большой прирост к будням?
2. **Замолчавшие ряды.** Сколько рядов «магазин × товар» продавались раньше, но не продали ни
   одной единицы за последние 7 дней периода (с 2024-06-26)? Реши через `ANTI JOIN` ко
   множеству рядов с продажами за эти дни и проверь другим способом. Сколько из них в эти дни
   стояли без товара на полке?
3. **Итоги по уровням.** Продажи: город × магазин, итог по городу, итог по сети — одним
   запросом через `ROLLUP` с колонкой `grouping()`. Сколько строк в результате и почему столько?
4. **Доля праздников.** Для каждого города — доля продаж, пришедшихся на дни с
   `holiday_flag = 1`, через `FILTER`. Сравни с долей таких дней в периоде.
5. **Поймай размножение.** Построй «справочник погоды» на уровне города и дня, соедини с продажами
   и покажи, во сколько раз выросла сумма. Затем построй его на правильном уровне и покажи, что
   сумма совпала с исходной. Проверь уникальность ключа обоих справочников.

### Оконные функции (урок 02)

6. **Скачок к вчера.** Для магазина 214 найди ряд и день с самым большим ростом продаж к
   предыдущему дню (`lag`).
7. **Половина периода.** Для каждого города — дата, когда накопительный итог продаж превысил
   50% продаж города за весь период.
8. **Сглаживание.** Скользящее среднее 7 дней дневных продаж по сети. В какую неделю периода оно
   максимально? Объясни, почему для FreshRetail `ROWS` и `RANGE … INTERVAL` здесь дают одно и то
   же.
9. **Топ-3 по городам.** Топ-3 товара каждого города по продажам. Сравни результат
   `row_number` и `dense_rank`: есть ли города, где они различаются, и почему.
10. **Доля в категории.** Для магазина 0 — доля каждого товара в продажах его категории первого
    уровня (окно поверх `GROUP BY`). Какой товар занимает самую большую долю своей категории?
11. **Лучший день магазина.** Для каждого магазина — день максимальных продаж через `QUALIFY`.
    Сколько раз лучшим днём оказывался выходной?
12. **Квартили магазинов.** Раздели магазины на 4 группы по суммарным продажам (`ntile`).
    Средняя доля часов без товара в каждой группе — что видно?
13. **Острова дефицита.** Найди самую длинную серию дней подряд, когда товар отсутствовал все 16
    часов (`stock_hour6_22_cnt = 16`). Выведи топ-5 рядов: магазин, товар, начало, конец,
    длина. `PARTITION BY` по ряду обязателен.
14. **Первая и последняя неделя.** Для каждого ряда магазина 0 — отношение средних продаж
    последних 7 дней к первым 7 дням (`first_value` / `last_value` с правильной рамкой или иначе).
15. **Неделя к неделе.** Продажи сети по дням и изменение к тому же дню неделю назад
    (`lag(…, 7)`). Почему сравнивать с прошлой неделей честнее, чем со вчера?

**Steps:**
1. Решай по порядку: задачи 1–5 после урока 01, 6–15 после урока 02.
2. Для каждой задачи сначала запиши ожидание (порядок величины), потом запрос.
3. Если результат удивил — проверь grain и соединения (урок 01, шаг 2), а потом рамку окна
   (урок 02, шаг 3).
