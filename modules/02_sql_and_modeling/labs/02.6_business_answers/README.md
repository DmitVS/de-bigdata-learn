## Tasks

### Task 1. Ответы

**Expected result / Definition of Done:**
- Три вопроса из своих карточек, разные по теме; для каждого — запрос к звезде в `answers.sql`
- Для каждого — ответ в README в форме «решение: …, потому что метрика … = …»; где вопрос вида
  «влияет ли X на Y» — сравнение внутри однородных срезов
- Если для ответа звезды не хватило — что добавлено в модель и почему (с правкой лабы 02.3)

**Steps:**
1. Перечитай карточку: решение, метрика, разрез, сигнал.
2. Напиши запрос к звезде; сверь итог с запросом к исходным файлам.
3. Используй окна там, где вопрос про динамику или рейтинг.
