## Tasks

### Task 1. Проектирование и разворот

**Expected result / Definition of Done:**
- В README: grain новой таблицы одним предложением, список колонок с типами и обоснованием
  (какие колонки дня взять с собой, какие оставить в дневной таблице и почему — урок 04, 2NF)
- Файл `data/silver/sales_hourly.parquet` создан одним запросом `COPY`; время записи и размер
  файла записаны в README

**Steps:**
1. Реши, какие колонки исходной строки нужны в почасовой таблице. Подумай, что станет с
   `discount` и погодой, если их повторить 24 раза.
2. Выбери узкие типы для часа и флага (урок 03, шаг 4).
3. Отладь запрос на одном магазине, затем запусти на всех данных с `.timer on`.
4. Создай папку `data/silver/` (в `make shell`: `mkdir -p data/silver`), она не попадёт в git.

### Task 2. Проверки

**Expected result / Definition of Done:**
- Три проверки из урока 03, шаг 3, — каждая запросом в `queries.sql` с результатом в README:
  число строк, сходимость сумм по дню (с допуском), уникальность ключа и диапазон часа
- Дополнительно: число часов без товара между 6:00 и 22:00 по развёрнутой таблице совпадает с
  `stock_hour6_22_cnt` исходной строки

**Steps:**
1. Для сумм сгруппируй развёрнутую таблицу обратно до дня и соедини с исходной по ключу дня.
2. Для четвёртой проверки определи, какие значения `hour` соответствуют окну 6:00–22:00.
   Ошибка на единицу здесь — главная ловушка лабы.

### Task 3. Разбиение и сравнение

**Expected result / Definition of Done:**
- Та же таблица записана с `PARTITION_BY` по месяцу в `data/silver/sales_hourly_by_month/`
- Запрос «распределение продаж по часам суток за май» выполнен по трём источникам: исходные
  массивы, `sales_hourly.parquet`, разбитая папка; время каждого (не меньше 10 запусков, p50)
  и объяснение разницы в README

**Steps:**
1. Для исходных массивов придумай способ без разворота всей таблицы — например, через
   `list_transform` или `unnest` после фильтра по месяцу.
2. Замерь каждый вариант скриптом из модуля 01 (урок 05, шаг 3) или `.timer on`.
3. Объясни разницу через то, сколько данных читает каждый вариант (урок 07, шаг 3).

### Task 4. Отчёт в широкой форме

**Expected result / Definition of Done:**
- `PIVOT`: средние продажи по часу суток (строки) и дню недели (колонки) для сети; значения
  дней недели перечислены явно
- Одно наблюдение о пиках продаж в будни и выходные
