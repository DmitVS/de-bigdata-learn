## 01 · Parquet изнутри

Уровни Parquet-файла?
?
Группы строк → куски колонок → страницы; в конце подвал со схемой и метаданными каждой группы и колонки.

Зачем группы строк в колоночном файле?
?
Писать потоком с памятью на одну группу; внутри группы колонки лежат отдельно — чтение остаётся колоночным.

Почему подвал должен быть маленьким?
?
Его читают при каждом обращении к файлу, до любых данных.

Что такое словарное кодирование и RLE?
?
Словарь: значения → номера из словаря. RLE: серия одинаковых значений → «значение × сколько раз».

Что умеют статистики min/max?
?
Только исключать: значение вне [min, max] — группы точно нет; внутри — может быть.

Почему фильтр по дате не отсекает ни одной группы в train.parquet?
?
Строки упорядочены по магазину и товару; каждая группа содержит весь диапазон дат.

Чем плох наш train.parquet и что дала перезапись?
?
Группы по 1 000 строк: 4 500 групп, подвал 9,5 МБ. С группами ~123 тыс. — 37 групп, подвал 75 КБ, файл 106 → 61,5 МБ.

Что за -0.0 в статистиках sale_amount?
?
Отрицательный ноль: равен 0.0, проверку < 0 не нарушает, но min() его покажет.

## 02 · Arrow и форматы

Что такое Apache Arrow?
?
Стандарт раскладки колоночных данных в памяти; библиотеки передают буферы без копирования (zero-copy).

Почему не переводить данные в объекты Python построчно?
?
Дорого: 200 тыс. строк → словари 152 мс, весь набор ~3,7 с; считать в DuckDB, Polars, pyarrow.compute.

Что возвращает .arrow() в DuckDB 1.5?
?
RecordBatchReader — поток. Для таблицы — to_arrow_table(); PyIceberg не пишет поток в партиционированную таблицу.

Почему нельзя назвать переменную at для DuckDB?
?
AT — ключевое слово time travel: FROM at даёт Parser Error.

CSV vs JSON vs Parquet zstd на eval без массивов?
?
25 МБ · 116,7 МБ · 1,1 МБ; avg по CSV 43 мс против 1 мс.

Почему для хранилища zstd, а не snappy?
?
Пишут один раз, читают много: меньше байт из S3 при каждом запросе, распаковка почти так же быстра. Умолчание Iceberg.

Когда Avro, а не Parquet?
?
Поток сообщений: записи по одной, схема с правилами эволюции (Kafka, модуль 08).

## 03 · Iceberg на практике

Что делает table.overwrite(df) без условия?
?
Заменяет всю таблицу: снапшоты delete всего + append нового.

Copy-on-write vs merge-on-read?
?
CoW переписывает файл без удалённых строк (PyIceberg); MoR пишет файл удалений, применяемый при чтении (Spark, Flink).

Как прочитать прошлую версию в DuckDB?
?
FROM t AT (VERSION => snapshot_id) или AT (TIMESTAMP => TIMESTAMPTZ '…').

Что делает rollback_to_snapshot?
?
Переставляет указатель текущей версии на старый снапшот; плохой снапшот остаётся в истории с is_current_ancestor = false.

Почему тысяча мелких файлов медленнее одного крупного?
?
На каждый файл — запрос к S3, подвал Parquet и запись в манифесте.

Что остаётся в S3 после expire_snapshots?
?
Все файлы: expire убирает ссылки; удаление файлов — remove orphan files (Spark).

Iceberg vs Delta vs Hudi?
?
Iceberg — независим от движка, скрытые партиции, REST-каталог; Delta — интеграция со Spark/Databricks; Hudi — частые обновления по ключу.

Зачем REST-каталог?
?
Хранит единственный указатель на текущий metadata.json и атомарно его переключает через стандартный HTTP-API; Lakekeeper ещё выдаёт временные ключи S3.

## 04 · Эволюция схем

Обратная vs прямая совместимость?
?
Обратная — новый код читает старые данные; прямая — старый код читает новые данные.

Почему переименование в Iceberg безопасно?
?
Колонки связаны с файлами по постоянному ID поля; имя меняется только в схеме.

Что будет при переименовании колонки в «голом» Parquet?
?
Без union_by_name — ошибка schema mismatch; с ним — две половинчатые колонки с NULL.

Какие изменения типов разрешены в Iceberg?
?
Только расширение: int → long, float → double, рост точности decimal. long → int, string → long — ValidationError.

Освобождает ли delete_column место?
?
Нет: значения остаются в старых файлах и снапшотах до перезаписи и expire + remove orphans.

Что если в append лишняя колонка?
?
ValueError: сначала добавить её в схему; недостающая необязательная колонка допустима (NULL).

## 05 · Партиционирование и сортировка

Три уровня отсечения?
?
Партиции → файлы (min/max в манифестах) → группы строк Parquet.

Скрытое партиционирование — что это?
?
Спецификация «колонка → преобразование»; значение в манифесте; фильтр по самой колонке отсекает партиции.

Значение партиции month для мая 2024?
?
652 — месяцы от января 1970 (650 — март 2024).

Как выбрать гранулярность партиции?
?
Объём / число партиций ≥ ~100 МБ; иначе грубее или сортировка вместо партиции.

Почему не партиционировать по store_id?
?
898 партиций с крошечными файлами; для магазина — сортировка.

Эффект сортировки по магазину у нас?
?
Фильтр по магазину: 1 файл из 20 вместо 11, 9 мс вместо 49 мс.

Сортирует ли PyIceberg по объявленному sort_order?
?
Нет (0.12): сортировать самому ORDER BY перед append; Spark соблюдает сам.

Чем мерить отсечение?
?
plan_files(): число и байты файлов; Total Files Read в EXPLAIN ANALYZE DuckDB; p50 времени.

Как сменить партицию месяца на день без переписывания данных?
?
with t.update_spec() as u: u.remove_field("sale_month"); u.add_field("sale_date", DayTransform(), "sale_day"). Старые файлы остаются с месячной партицией. Без remove_field Lakekeeper откажет: redundant partition.
