## Tasks

### Task 1. Таблица и дозапись по дням

**Expected result / Definition of Done:**
- Таблица `sandbox.sales_daily` (магазин, товар, дата `date`, продажи, скидка) создана из
  PyIceberg; в неё 7 раз дописаны продажи 7 дней мая — по одному дню за `append`
- `inspect.snapshots()` и `inspect.files()`: 7 снапшотов, число файлов; в README — почему файлов
  столько

### Task 2. Ошибка и откат

**Expected result / Definition of Done:**
- Восьмой `append` повторяет день 7 (имитация дубля); запрос показывает задвоение
- Найден «плохой» снапшот, прочитана версия до него в PyIceberg **и** в DuckDB (`AT (VERSION => …)`)
- Таблица откачена; `inspect.history()` показывает отменённый снапшот

### Task 3. Замена и удаление по условию

**Expected result / Definition of Done:**
- Продажи за день 3 заменены исправленными (`overwrite` с `overwrite_filter`), строки магазина 0
  удалены (`delete`)
- Для каждой операции из сводки снапшота: сколько файлов добавлено и удалено; объяснение через
  copy-on-write
- Контрольная проверка: `overwrite` без условия на копии таблицы — что осталось и почему

### Task 4. Эволюция схемы

**Expected result / Definition of Done:**
- Одной транзакцией: добавлена `activity_flag`, `sale_amount` переименована в `sales`, тип одной
  `int`-колонки расширен до `long`
- Попытка сузить тип и попытка дописать данные с лишней колонкой — обе ошибки записаны дословно
  с объяснением
- Старый снапшот прочитан после изменений: какие имена колонок и почему

### Task 5. Обслуживание

**Expected result / Definition of Done:**
- 30 мелких `append` по одной тысяче строк → `inspect.files()`; затем ручное уплотнение
  перезаписью; число и средний размер файлов до и после
- `expire_snapshots` всех снапшотов кроме текущего; число файлов в S3 под префиксом таблицы до и
  после — объяснение, почему не уменьшилось
- Песочница удалена (`purge_table`, `drop_namespace`)

**Steps (для всех задач):**
1. Шаблоны вызовов — в шпаргалке урока 03; выражения фильтров — `pyiceberg.expressions`.
2. Файлы в S3 считай через `s3fs` по `table.location()` (модуль 00, урок 04).
3. После каждой задачи записывай в README только выводы и объяснения, не копируй вывод целиком.
