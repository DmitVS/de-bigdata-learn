## Tasks

### Task 1. Запись в шести форматах

**Expected result / Definition of Done:**
- Один и тот же набор — все строки обоих файлов, все колонки **кроме** массивов — записан в:
  CSV, JSON (`newline_delimited`), Parquet `uncompressed`, `snappy`, `zstd` (уровень по
  умолчанию), `zstd` уровень 9
- Таблица: формат → размер → время записи → во сколько раз меньше CSV
- Отдельно: Parquet `zstd` с массивами `hours_sale` и `hours_stock_status` — сколько весят массивы

**Steps:**
1. Запиши через `COPY … TO` в DuckDB с `.timer on` (урок 02, шаг 3).
2. Размер — `ls -l` или `read_blob`.

### Task 2. Чтение: три типа запросов

**Expected result / Definition of Done:**
- Для каждого формата — p50 из 10 запусков трёх запросов: (а) `avg(sale_amount)` по всей
  таблице; (б) сумма продаж магазина 214; (в) `SELECT *` строк одного дня
- Таблица и объяснение порядка форматов через устройство (колонки, отсечение, разбор текста)

**Steps:**
1. Замеряй скриптом из модуля 01 или `.timer on` с ручными повторами.
2. Для (в) объясни, почему разрыв между CSV и Parquet меньше, чем для (а).

### Task 3. DuckDB → Arrow → Polars

**Expected result / Definition of Done:**
- Замер: чтение 5 колонок из Parquet в Arrow-таблицу, передача в Polars, перевод 200 тыс. строк
  в Python-объекты; таблица времени
- Одна агрегация (продажи по магазинам) тремя способами — DuckDB, Polars, `pyarrow.compute` или
  `pa.Table.group_by` — результаты совпадают
