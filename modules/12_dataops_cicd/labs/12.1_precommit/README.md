# Лаба 12.1 · Свой репозиторий курса и pre-commit

**Модуль:** [12 · DataOps и CI/CD](../../README.md) · **Дата начала:** YYYY-MM-DD · **Статус:** ⬜

## Objective

Вынести курс в отдельный репозиторий (решение `memory/decisions/ci-separate-repo.md`) и
поставить проверки перед каждым коммитом так, чтобы на хосте по-прежнему были нужны только
docker и make. После лабы ни один коммит с `.env`, сломанным YAML или неотформатированным кодом
не попадёт в историю.

## Tasks

### Task 1. Отдельный репозиторий

**Expected result / Definition of Done:**
- Курс — отдельный git-репозиторий на GitHub с историей папки `DE_BigData_Learn` (не одним
  коммитом «всё сразу»); общий `repo/` не изменён
- В новом репозитории нет `.env`, данных и скачанных пакетов (проверено по `git ls-files`)
- В README — какой способ переноса истории ты выбрал и почему

**Steps:**
1. Выбери способ сохранить историю папки: `git subtree split` или `git filter-repo --subdirectory-filter`
   (второй — в контейнере, например в образе workspace).
2. Создай пустой репозиторий на GitHub и отправь туда результат.
3. Клонируй новый репозиторий в новую папку и подними стек из неё: `make init`, `make up`, `make check`.

### Task 2. Хуки

**Expected result / Definition of Done:**
- `make hooks` установил хук; коммит с намеренной ошибкой стиля Python отклонён, после `make fmt`
  — принят (вывод обоих коммитов в README)
- Попытка закоммитить `.env` (`git add -f .env`) отклонена хуком `no-env-file`
- `make precommit ARGS="--all-files"` проходит без ошибок; что пришлось исправить в репозитории —
  в README

**Steps:**
1. `make hooks`, затем проверь хук на трёх намеренных ошибках: Python, YAML, `.env`.
2. Прогони все файлы и разберись с каждым `Failed`.

### Task 3. Свой хук

**Expected result / Definition of Done:**
- В `.pre-commit-config.yaml` добавлен хук, которого нет в образце и который полезен курсу
  (например: проверка, что у каждой модели в `models/marts` есть описание; или запрет файлов
  больше 1 МБ в `modules/`; или проверка STE `scripts/ste_check.py` для изменённых уроков)
- Хук срабатывает на намеренной ошибке и молчит на чистом репозитории
