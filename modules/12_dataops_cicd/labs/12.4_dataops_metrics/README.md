## Tasks

### Task 1. DORA по истории

**Expected result / Definition of Done:**
- В `ops/dora.md` — четыре метрики за последние 4 недели с командами или запросами, которыми они
  получены (git log, API GitHub или `gh`, журнал инцидентов)
- Размер изменений: медиана и максимум строк на pull request; самый большой pull request и
  почему он таким получился

### Task 2. DORA и SLO вместе

**Expected result / Definition of Done:**
- Таблица по неделям: выкатки, неудачные выкатки, дни вне SLO данных, их причины (код или
  источник)
- Решение по правилу бюджета ошибок: где бюджет исчерпан и что команда должна была бы сделать

### Task 3. Одно улучшение

**Expected result / Definition of Done:**
- Выбрана одна метрика, которую ты улучшишь, и одно изменение процесса (меньше pull request,
  быстрее CI, новый тест, новый хук)
- Через неделю — замер «до/после» в `ops/dora.md`
